The goal of this project is to create AI-generated website copy for a local business using structured prompts and prompt engineering techniques.

# Business Type Tone Adaptation

### Friendly Tone (Salon/Cafe)
Warm, welcoming, simple, and conversational.

Example:
“Treat yourself to a relaxing beauty experience you deserve.”

### Professional Tone (Clinic/Agency)
Professional, confident, informative, and trust-focused.

Example:
“Trusted healthcare solutions delivered with professional care and advanced technology.”
